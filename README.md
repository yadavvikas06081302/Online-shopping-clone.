# ShopNest - Online Shopping Clone

A responsive online shopping clone developed with **HTML, CSS and JavaScript**.

## Author
**Vikas Yadav**

## Features
- Product search
- Category filtering
- Price/rating sorting
- Product details modal
- Add to cart
- Quantity controls
- Wishlist
- LocalStorage persistence
- Demo checkout
- Demo order history
- Newsletter subscription UI
- Responsive mobile design

## Run
Open `index.html` in a browser.

For GitHub Pages:
1. Upload all files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/root`.
5. Save.

## Files
- `index.html`
- `style.css`
- `script.js`
- `README.md`

> This is a frontend/demo project. No real payment is processed.
